# Rotom Reader Heart (Gen 2)

Heart, a warm female narrator, reading every line of Gold, Silver and Crystal, plus a word pack for names and numbers.

A voice pack for [Rotom Reader](https://github.com/ElvieBlooms/rotom_reader). Install it alongside Rotom Reader 0.4.0 or newer; on its own it does nothing. It only loads on Gold, Silver and Crystal.

Recorded with Rotom Reader's recorder (`tools/build_voice.py`) using Kokoro-82M by hexgrad (Apache 2.0). MIT licensed.
